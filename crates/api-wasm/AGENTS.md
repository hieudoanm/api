# AGENTS.md — api-wasm

WebAssembly bindings for `api-core`. See the root [`AGENTS.md`](../../AGENTS.md).

- `src/lib.rs` — `#[wasm_bindgen]` exports only; all conversion logic lives in
  `api-core`. No duplicated parsing/emitting.
- Exported functions: `formats()`, `openapi_info(source)`,
  `convert(source, format, name, base_url)`, `convert_all(source, name,
base_url)` — all return JSON strings; errors surface as `JsError`.
- `crate-type = ["cdylib", "rlib"]` — `cdylib` for the wasm artifact, `rlib`
  so Rust consumers/tests can link it natively.
- JS callers pass empty strings for `name`/`base_url` to mean "unset" —
  `optional()` trims and maps `""` → `None`. Keep that contract.
- Adding a format requires no changes here — `formats()`/`convert()` pick it
  up from `ClientFormat::ALL` automatically.
- `package.json` + `Makefile` make this crate a pnpm workspace package
  (`@api/wasm`); `packages/landing` depends on it via `workspace:*`.
- `pkg/` is generated by `make build-wasm` (`wasm-bindgen --target web`) and is
  gitignored — CI builds it before the landing build. Do not hand-edit it.
- Build: `make build-wasm` or `pnpm --filter @api/wasm run build:wasm`
  (needs the `wasm32-unknown-unknown` Rust target and `wasm-bindgen` CLI
  `0.2.130`, matching `Cargo.toml`).
